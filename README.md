# CareerTrack_Job_Application_Tracker

CareerTrack is a Python-based Job Application Tracker designed to help users organize and manage their job and internship applications efficiently.

## 📌 Problem Statement

When applying to multiple jobs or internships, it can be difficult to keep track of companies, job roles, application dates, interview stages, and follow-up dates.

CareerTrack provides a simple command-line application to store, manage, search, filter, and organize job applications.

## 🎯 Objective

The objective of this project is to develop a functional Python application that demonstrates:

- Modular programming
- Data structures
- Input validation
- File handling
- JSON data persistence
- CRUD operations
- Searching, filtering and sorting
- Exception handling
- Testing and documentation

## ✨ Features

- ➕ Add a new job application
- 📋 View all applications
- ✏️ Update application details
- 🗑️ Delete applications
- 🔍 Search applications
- 🔽 Filter applications
- ↕️ Sort applications
- 📊 View application dashboard
- 💾 Persistent JSON data storage
- ✅ Input validation
- ⚠️ Error and exception handling
- 🆔 Automatic unique ID generation

## 🛠️ Technologies Used

- Python 3
- JSON
- File Handling
- Lists and Dictionaries
- Functions and Modular Programming
- Command Line Interface
- Virtual Environment
